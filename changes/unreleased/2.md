## 2026-10-30 - Read-only DAG viewer (#2)

`omo dag watch` renders a running `mass ulw` DAG run in the terminal without booting the engine. It resolves the store through senpi-task's read-only helper, validates checkpoints, bounds WAL backfill, and never writes `.in-project`, adopts a legacy in-project store, or changes run state. `--once` and `--json` cover scripts and CI, and the compiled `omo` entry dispatches the viewer directly.
